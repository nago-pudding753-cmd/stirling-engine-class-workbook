# ねつと、うごき。 — スターリングエンジン実習

添付指導書の授業計画に合わせ、第1週の理論計算から第14週の性能コンテスト・報告会までを順番に進める授業用Webアプリです。各週の課題チェック、設計計算、AutoCAD互換DXF出力、提出記録をまとめています。

## 起動方法

1. このフォルダーで `npm install` を実行
2. `npm run dev` を実行
3. 表示されたローカルURLをブラウザーで開く

## 公開サイトにする（GitHub Pages）

**公開サイト：** https://nago-pudding753-cmd.github.io/stirling-engine-class-workbook/

ソースコードは https://github.com/nago-pudding753-cmd/stirling-engine-class-workbook で公開しています。GitHub Pagesへの自動公開ワークフローも設定済みです。

既定ブランチ `main` へのpushごとにActionsがビルドし、`dist/` をGitHub Pagesへ再公開します。

再公開設定は [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) にあります。独自ドメインを使う場合はPages設定で別途登録してください。

## アプリでできること

- 14週の順次学習：理論計算、製図、工程表、旋盤・フライス・ワイヤカット、組立、試験、変更検討、発表
- 指導書§2.2の共通条件（$D_p=16\,\mathrm{mm}$、$S_p=8\text{–}14\,\mathrm{mm}$、$P_{mean}=129\,\mathrm{kPa}$、$\kappa=1$、$\alpha=90^\circ$）を基準に計算
- 行程容積、無効容積、加熱キャップ/連結穴寸法、ピストン長さ、経験式回転数、Schmidt理論P–V線図、出力・慣性モーメントを表示
- AutoCADで開けるASCII DXF R12（AC1009、mm単位）としてα形エンジンの学習用組立概略図をダウンロード
- 週ごとの完了チェック、入力値、進捗をブラウザーのローカルストレージに保存
- 学習記録・計算条件をテキスト形式で出力

入力した班名・設計条件・学習進捗は利用中のブラウザー内に保存され、サーバーへ送信しません。別の端末・ブラウザーとの共有や教員への自動提出機能はありません。

設計コンセプトから寸法や機構をAIで自動発明するものではなく、指導書の既定条件・計算手順に沿って学習者が入力・確認するワークブックです。DXFはCAD互換形式ですが、現段階で出力するのは寸法・配置を確定した製作用図面ではなく、単位mmの機構学習用概略図です。部品図、第三角法の組立図、寸法公差付き加工図、切削条件の自動生成には対応していません。

## 添付指導書を反映した点

添付「2026年度_プロダクションプラクティス_指導書本文」PDFを確認し、設計条件・提出様式・週ごとの授業日程・加工注意を反映しています。

- 授業日程表に沿い、第1週に理論計算とP–V線図、第2週に設計・製図、第3週に工程表、第4–13週に製作・評価、第14週に性能コンテストと報告会を配置。
- 設計計算書の既定条件と、行程容積、作動空間、Schmidt理論、回転数、仕事・出力、はずみ車設計の流れを設計画面に配置。
- 図面作成の第三角法・原則1:1・材質・製作数の要件を案内。
- ピストン・シリンダー加工ではピストンを先に加工し、加熱ピストンを先行する。
- シリンダーは冷却フィン加工後に内径加工を行う。
- ピストンとシリンダーの寸法差、薄肉部の変形、組立後の動作範囲に注意し、最終寸法は教員の確認を受ける。
- 支柱・軸受位置等の変更は、連接棒・ピストン・フライホイールなど他部品に波及し得るため、寸法連鎖を確認する。
- 材料・工具の準備と納期を工程に含める。指導書では材料発注に約2週間かかる場合があると記載されている。
- バリによるけがを防ぐため、角の面取りを行う。

## 安全上の注意

DXF図面はAutoCAD互換の機構学習用概略で、製作図・加工図ではありません。教材の正式な部品図、第三角法の組立図、材料・工具、加工工程表を用意し、機械での加工前に教員確認を受けてください。回転数・切削条件を本アプリで決めず、機械の取扱いと教員の安全指示に従ってください。加熱・試運転は教員立会いで行ってください。公式様式、提出締切、最新版の日程は授業の案内を優先してください。
